# youtube-content-analysis-sql-

 ## Objective
Analyze YouTube content performance using SQL queries and KPI analysis.

## Tools Used
- SQL
- PostgreSQL
- pgAdmin 4

## KPIs Covered
- Total Views
- Total Likes
- Engagement Rate
- Top Categories
- Subscriber Growth
- Country-wise Analysis

## Project Insights
- Gaming category generated highest views.
- Educational videos showed strong engagement.
- High watch time indicates better audience retention.
